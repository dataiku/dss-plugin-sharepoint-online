- Use this dataset to read rows from a SharePoint Online list or write to a list as the output of a DSS recipe. Select it for list items rather than document files.
- For `auth_type="oauth"`, select an accessible `sharepoint_oauth` preset from `oauth-login`. For `auth_type="app-certificate"`, select `app_certificate` from `app-certificate`. For `auth_type="app-username-password"`, select `app_username_password` from `app-username-password`. Set the authentication method explicitly; the descriptor has no default.
- Presets provide the tenant and site path. Use them as opaque references. The authenticated user or application needs read access for reading and write access for writing. If authentication setup is incomplete, ask the user to finish it in DSS settings; do not request passwords, tokens, certificates, or private keys in chat.
- Set `sharepoint_list_title` to the exact list title, not its URL or ID. Ask for the intended list when it is unknown; the `DSS_${projectKey}_` default is not evidence of an existing list. List titles used for writing cannot contain `?`.
- To override the preset's site path, set `advanced_parameters=true` and `sharepoint_site_overwrite` to a path such as `sites/TeamSite/subsite`, not a full URL. Confirm the target site before writing.
- To read a particular view, set `advanced_parameters=true` and `sharepoint_list_view_title` to its exact name. Leave it empty to read without a named view. The view must exist; the connector follows pagination automatically. Inspect the detected schema before referencing columns: DSS column names come from SharePoint field display titles.
- Configure append or overwrite on the producing DSS recipe, such as the Sync recipe's "Append instead of overwrite" option. Append requires an existing list and adds new items; it does not update matching items. It can also create missing columns from the input schema. Retrying an append can duplicate items.
- Overwrite recycles the existing list and creates a new list with columns derived from the input schema. For a new list, use overwrite to create it. For an existing list, clarify ambiguous write intent before choosing overwrite; it replaces the list rather than only clearing rows.
- With `advanced_parameters=true`, `max_workers` controls write concurrency (1–5, default 1) and `batch_size` controls items per batch (1–100, default 100). Multiple workers can change item order.
- For text longer than 255 characters, use existing multiple-line text columns or enable `advanced_parameters=true` and `allow_string_recasting=true` to allow conversion to multiple-line text. Single-line text values can be truncated to 255 characters if conversion is disabled or fails.
- Saving configuration does not write SharePoint items. Previewing and schema detection access SharePoint; executing a producing recipe writes to the remote list. Run or retry writes only when the user's request authorizes that operation.
